# OpenAPI

The documentation build generates the schema directly from the FastAPI application. It is not
maintained by hand.

- [Download the static OpenAPI schema](openapi.json)
- A running instance serves the same generated contract at `/openapi.json`.
- A running instance provides Swagger UI at `/docs` and ReDoc at `/redoc`.

The static schema is regenerated by `make docs-build` and `make docs-serve`. Pull requests fail if
the strict documentation build cannot consume it.
