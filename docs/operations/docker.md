# Docker and releases

## Run the image

```bash
docker build -t prelum:latest .
docker run --rm -p 9870:9870 \
  -e PRELUM_API_TOKEN=replace-me \
  -e PRELUM_FONT_PATH=/opt/prelum/fonts \
  -e PRELUM_LOCAL_PACKAGE_PATH=/opt/prelum/packages \
  -v "$PWD/fonts:/opt/prelum/fonts:ro" \
  -v "$PWD/packages:/opt/prelum/packages:ro" \
  prelum:latest
```

The Dockerfile copies Typst from an official version- and digest-pinned image. The runtime includes
DejaVu, Liberation and Montserrat fonts and runs as uid 10001. A mounted
`PRELUM_DEBUG_OUTPUT_DIR` must be writable by that uid.

## Published images

Published releases use `ghcr.io/vrtfinland/prelum:<tag>`. Each platform image contains an SPDX
SBOM and detailed SLSA v1 provenance generated by BuildKit. The final multi-platform manifest is
signed keylessly with Cosign using the publishing GitHub Actions workflow's OIDC identity.

Verify a release by immutable digest:

```bash
cosign verify \
  --certificate-identity-regexp \
    '^https://github.com/VRTFinland/prelum/.github/workflows/build.yml@refs/heads/main$' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  ghcr.io/vrtfinland/prelum@sha256:<digest>
```

## Manual release process

Releases are started manually from the `release` workflow on `main`. The requested stable semantic
version must match `pyproject.toml`. The workflow creates the `vX.Y.Z` tag, runs the complete test
and image publication workflow, and only then creates a GitHub release containing the immutable
image digest.

A retry continues a partial release only while its tag still points to the same commit. An existing
GitHub release is a successful no-op. Image publication and releases remain disabled while the
repository is private; CI still runs the complete test job.
